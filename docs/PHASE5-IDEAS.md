## Prioritization Criteria

When choosing what to build next, consider:

1. **Does it maintain ADHD-friendliness?** - No punishment, no pressure
2. **Does it add joy?** - Cozy, rewarding, delightful
3. **Is it technically feasible?** - Fits current architecture
4. **Does it bloat the bundle?** - Keep performance tight
5. **Can it be shipped incrementally?** - Sliceable into small PRs

## How to Propose New Ideas

1. Add to this document under appropriate category
2. Include brief description of the feature
3. Mark priority level (High/Medium/Low)
4. Consider ADHD-friendliness implications
5. Note any technical dependencies
