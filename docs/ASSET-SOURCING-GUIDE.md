# Asset Sourcing Guide for Homestead

This document maps the 93 catalog items to free/CC0 asset sources and provides step-by-step integration instructions.

## Free Asset Sources

### Primary Sources (CC0 - No Attribution Required)

1. **Kenney.nl Furniture Kit**
   - URL: https://kenney.nl/assets/furniture-kit
   - License: CC0 (Public Domain)
   - Contains: Sofas, beds, desks, tables, chairs, bookshelves, dressers, wardrobes, rugs, lamps
   - Format: PNG sprites (isometric and top-down)
   - Perfect for: Furniture, basic decor

2. **Kenney.nl Tiny Town**
   - URL: https://kenney.nl/assets/tiny-town
   - License: CC0
   - Contains: Outdoor items, benches, planters, paths
   - Good for: Outdoor category items

3. **Kenney.nl Holiday Kit**
   - URL: https://kenney.nl/assets/holiday-kit
   - License: CC0
   - Contains: Christmas trees, wreaths, stockings, snow globes
   - Perfect for: Seasonal winter/holiday items

### Secondary Sources (CC-BY or CC0)

4. **itch.io - Cozy Interior Pack** (various artists)
   - Search: "cozy interior pixel art" or "furniture pixel art"
   - Many free packs with Attribution license
   - Contains: Plants, mugs, books, candles, decorative items

5. **OpenGameArt.org**
   - URL: https://opengameart.org
   - Search: "furniture", "interior", "decoration"
   - Mixed licenses - always check individual asset
   - Good for: Wall art, seasonal items, unique pieces

6. **CraftPix - Free Section**
   - URL: https://craftpix.net/freebies/
   - Contains: Themed asset packs (Halloween, Christmas)
   - Good for: Seasonal items

## Integration Walkthrough

### Step 1: Download Assets

1. **Kenney Furniture Kit** (Primary - covers ~60% of items)
   ```
   https://kenney.nl/assets/furniture-kit
   ```
   - Click "Download" (free)
   - Extract the ZIP file

2. **Kenney Holiday Kit** (Seasonal items)
   ```
   https://kenney.nl/assets/holiday-kit
   ```

3. **Kenney Tiny Town** (Outdoor items)
   ```
   https://kenney.nl/assets/tiny-town
   ```

4. **itch.io packs** (Search and download as needed)
   - Go to itch.io > Game Assets > Free
   - Search "cozy pixel art" or "furniture sprites"

### Step 2: Organize Asset Folder Structure

Create this structure in `public/assets/`:

```
public/
└── assets/
    └── sprites/
        ├── furniture/
        │   ├── furniture_sofa_blue.png
        │   ├── furniture_sofa_cream.png
        │   ├── furniture_bed_single.png
        │   └── ...
        ├── decor/
        │   ├── decor_plant_fern.png
        │   ├── decor_lamp_floor.png
        │   └── ...
        ├── rug/
        │   ├── rug_basic.png
        │   ├── rug_round_cream.png
        │   └── ...
        ├── wall/
        │   ├── wall_poster_simple.png
        │   ├── wall_clock_round.png
        │   └── ...
        ├── surface_decor/
        │   ├── surface_mug_coffee.png
        │   └── ...
        ├── outdoor/
        │   ├── outdoor_bench_wooden.png
        │   └── ...
        ├── wall_finish/
        │   ├── wall_finish_cream.png
        │   └── ...
        └── floor_finish/
            ├── floor_finish_warm_wood.png
            └── ...
```

### Step 3: Process Downloaded Assets

For each downloaded asset:

1. **Rename** to match the `textureKey` in catalog.json
   - Example: `sofa_3seater.png` → `furniture_sofa_blue.png`

2. **Resize** if needed to match game grid
   - 1 footprint unit = 32px (configurable)
   - A 2x2 item = 64x64px sprite

3. **Recolor** variants (if making color variants from one asset)
   - Use image editor (GIMP, Photoshop, etc.)
   - Adjust hue/saturation for color variants

4. **Export** as PNG with transparency

### Step 4: Update the Asset Manifest

Edit `src/game/content/manifest.json` to register all assets:

```json
{
  "version": 1,
  "description": "Game asset manifest for Homestead",
  "assets": {
    "furniture_sofa_blue": {
      "type": "image",
      "path": "/assets/sprites/furniture/furniture_sofa_blue.png",
      "width": 128,
      "height": 64,
      "description": "Blue 3-seater sofa"
    },
    "furniture_bed_single": {
      "type": "image",
      "path": "/assets/sprites/furniture/furniture_bed_single.png",
      "width": 64,
      "height": 96,
      "description": "Single bed"
    }
    // ... add all 93 items
  }
}
```

### Step 5: Update HouseScene to Load Real Sprites

In `src/game/scenes/HouseScene.ts`, modify the asset loading:

```typescript
// In preload():
preload() {
  // Load manifest
  this.load.json('manifest', '/assets/manifest.json');
}

// In create() or a loader scene:
const manifest = this.cache.json.get('manifest');
for (const [key, asset] of Object.entries(manifest.assets)) {
  if (asset.type === 'image') {
    this.load.image(key, asset.path);
  }
}
```

### Step 6: Render Actual Sprites Instead of Rectangles

Update the item rendering code to use loaded textures:

```typescript
// Instead of:
const rect = this.add.rectangle(x, y, width, height, color);

// Use:
const sprite = this.add.image(x, y, item.textureKey);
// If texture doesn't exist, fall back to colored rectangle
if (!this.textures.exists(item.textureKey)) {
  sprite.setVisible(false);
  const fallback = this.add.rectangle(x, y, width, height, 0x888888);
}
```

### Step 7: Update CREDITS.md

For each asset used, add attribution:

```markdown
## Art Credits

### Kenney.nl (CC0 - Public Domain)
- Furniture Kit: https://kenney.nl/assets/furniture-kit
- Holiday Kit: https://kenney.nl/assets/holiday-kit
- Tiny Town: https://kenney.nl/assets/tiny-town

### itch.io Artists (CC-BY)
- [Artist Name] - [Pack Name]: [URL]
  License: CC-BY 4.0
```

## Quick Start: Minimum Viable Art

To get started quickly with placeholder art that looks better than colored rectangles:

1. Download just **Kenney Furniture Kit**
2. Use the included sprites for ~40 furniture items
3. For missing items, create simple colored rectangles in an image editor:
   - Wall finishes: solid color PNGs
   - Floor finishes: simple pattern tiles
   - Seasonal items: can remain as placeholders until needed

This gets you from "colored rectangles" to "actual furniture sprites" in about an hour of work.
